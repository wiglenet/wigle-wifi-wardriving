บัญชีของคุณ
ขีดจำกัดการค้นหาเริ่มต้นที่ระดับต่ำ แต่จะเพิ่มขึ้นเองตามธรรมชาติเมื่อเวลาผ่านไป พร้อมกับการทำงานที่ดี
โทเค็น API
WiGLE ให้บริการการเข้าถึงระบบต่างๆ ของเราผ่าน API ซึ่งช่วยให้เราสามารถให้สิทธิ์การเข้าถึงแก่ผู้ที่ต้องการใช้ข้อมูลเพื่อวัตถุประสงค์ทางการค้า และผู้ที่ต้องการใช้ข้อมูลในปริมาณมากจนเกินกำลังเซิร์ฟเวอร์ของเรา ในขณะเดียวกันก็ช่วยสนับสนุนโครงการนี้ด้วย ปัจจุบัน การเข้าถึง API สำหรับบางฟังก์ชันถูกจำกัดในแต่ละวันสำหรับผู้ใช้ทุกคน แต่หากคุณต้องการการเข้าถึงที่เพิ่มขึ้น โปรดส่งอีเมลถึงเรา (ระบุชื่อผู้ใช้และกรณีการใช้งานของคุณ) ที่WiGLE-admin@wigle.netเอกสารประกอบมีอยู่ที่api.wigle.netโปรดจำไว้ว่าการลงทะเบียนใช้งาน WiGLE คุณจะต้องปฏิบัติตามข้อตกลงใบอนุญาตผู้ใช้ปลายทาง ของเรา หากคุณวางแผนที่จะใช้ข้อมูล WiGLE เพื่อผลกำไรของคุณเอง คุณจะต้องขออนุญาตใช้ข้อมูลในเชิงพาณิชย์ คุณสามารถสอบถามเกี่ยวกับตัวเลือกเชิงพาณิชย์ได้โดยส่งอีเมลถึงเราที่ WiGLE-admin@wigle.net

การตรวจสอบสิทธิ์การเข้าถึง API จะดำเนินการโดยใช้ส่วนหัว HTTP "Authorization" ( ไม่ใช่พารามิเตอร์ auth_token) และการตรวจสอบ สิทธิ์แบบ Basic authentication โดยใช้ "User" และ "Key" ด้านล่างเป็นชื่อผู้ใช้และรหัสผ่านในการตรวจสอบสิทธิ์แบบ Basic authentication คุณจะสามารถเข้าถึง API ได้โดยไม่ต้องใช้การตรวจสอบสิทธิ์แบบเซสชัน ไลบรารีหลายแห่งรองรับ Basic authentication แต่คุณสามารถใช้โทเค็น "Encoded for Use" ด้านล่างโดยตรง หรือดำเนินการด้วยตนเองโดยการต่อกันเป็น<api user> : <api key>และ เข้ารหัส ผลลัพธ์ด้วย Base64 สตริงที่เข้ารหัสแล้วจะต้องวางไว้ในส่วนหัว HTTP Authorizationในสตริงที่อ่านว่าBasic <encoded string >

คุณสามารถทดสอบข้อมูลประจำตัวของคุณได้โดยการใส่ชื่อ APIและโทเค็น APIลงใน ช่อง ชื่อผู้ใช้และรหัสผ่าน (ตามลำดับ) ใน กล่องโต้ตอบ การตรวจสอบสิทธิ์พื้นฐานที่คุณสามารถเข้าถึงได้โดยการคลิก ปุ่ม อนุญาตในเอกสาร API แบบโต้ตอบของเราเพื่อหลีกเลี่ยงความสับสนระหว่างการทดสอบ เราขอแนะนำให้คุณออกจากระบบ หรือทดสอบในหน้าต่างส่วนตัว/ไม่ระบุตัวตน เพื่อให้แน่ใจว่าคุณกำลังเข้าถึงระบบด้วยโทเค็นของคุณ แทนที่จะใช้การตรวจสอบสิทธิ์แบบเซสชันในฐานะผู้ใช้เว็บ"
